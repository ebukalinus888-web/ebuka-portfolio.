# Standard Operating Procedure: New Employee IT Setup
**Project type:** Practice portfolio project  
**Role demonstrated:** Help Desk / IT Operations

## Purpose
Offer a consistent checklist for preparing a new employee’s workstation and confirming that the basic setup works.

## Before setup
- Confirm the approved onboarding request and start date.
- Verify the required device, role, software, and access approvals.
- Confirm the assigned asset tag or device identifier.
- Follow company policy for identity verification and access provisioning.

## Setup checklist
- [ ] Inspect the device and power adapter.
- [ ] Record asset details in the approved inventory system.
- [ ] Install approved operating-system and security updates.
- [ ] Confirm endpoint protection and firewall status according to policy.
- [ ] Connect to the approved network.
- [ ] Verify required business applications are installed.
- [ ] Confirm account access only after appropriate authorization.
- [ ] Test audio, camera, keyboard, mouse, and any required peripherals.
- [ ] Share approved first-login instructions and support contact route.
- [ ] Record completion, exceptions, and outstanding actions.

## Handover
Tell the employee what is ready, what remains outstanding, and how to request help. Never share passwords in the ticket or an unsecured message.

## Completion criteria
The assigned device is recorded, approved updates and tools are checked, access is provisioned by authorized personnel, and the user can complete a basic sign-in and application test.

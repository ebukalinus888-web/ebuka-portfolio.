# Ebuka Wisdom Portfolio Website

A responsive, GitHub-ready portfolio covering three job directions:
- IT Support / Help Desk
- Customer Support / Customer Experience
- Sales / Business Development

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `ebuka-portfolio`.
2. Upload `index.html`, the `projects` folder, and this README.
3. In the repository, open **Settings → Pages**.
4. Choose the main branch and root folder, then save.
5. Wait for GitHub Pages to publish the site and copy the public URL into your CV.

## Before publishing
- Replace the email, LinkedIn, and GitHub placeholders in `index.html`.
- Verify every education and certificate detail.
- Keep credentials marked “in progress” until formally completed.
- Projects are practice examples, not client projects. Do not describe them as paid work.
- Add screenshots only when they contain no private information.

## Suggested repository description
`Portfolio for IT support, customer experience, and business development.`

## Suggested CV portfolio line
`Portfolio: [insert published GitHub Pages URL]`
